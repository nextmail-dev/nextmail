# 变更 0057：邮件搜索显式触发

日期：2026-07-29

## 背景

本地搜索的三个及以上 Unicode 字符使用 SQLite FTS5 trigram；一至两个字符为了支持中文短词，会在索引存储列上执行受限字面扫描。此前搜索框在停止输入 250ms 后自动提交，用户输入短关键词或在输入中停顿时，可能启动不需要的短词扫描。

## 已实施

- 将邮件列表搜索状态拆分为输入草稿和已提交关键词。
- 键入、停顿或继续编辑搜索框都不会改变 TanStack Query key，也不会调用 `search_messages`。
- 按 Enter 或点击搜索框右侧的搜索按钮后，才对去除首尾空白的当前文本发起搜索。
- 清空搜索框立即撤销当前搜索并恢复普通邮件列表；账户切换、文件夹切换和通知导航同时清除两种搜索状态。
- 搜索按钮和输入框沿用中英文“搜索当前文件夹”可访问名称，未引入浏览器原生表单外观。
- 删除不再使用的 `useDebouncedValue` 及其测试，不改变 SQLite schema、FTS 语料、短词兼容、分页或账户/文件夹隔离。
