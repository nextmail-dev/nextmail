# 变更 0055：邮件阅读、内联图片与窗口就绪显示优化

日期：2026-07-27

## 阅读界面

- 邮件标题移到阅读页顶部，标题下方由单一浅色细边框圆角容器组织发件人、收件人、抄送、附件概况、常用操作、正文和附件。
- 附件改为固定宽度左右结构：左侧按 PDF、文档、表格、演示、图片、压缩包、音视频、代码和未知类型展示克制的彩色 Lucide 图标，右侧显示文件名和大小；悬浮或键盘聚焦时显示打开/下载和另存为。
- 多附件区域使用既有覆盖式自绘滚动条，邮件标题、地址、附件名和正文继续允许选择复制。

## 内联图片

- CID URL 按 RFC 2392 解码 `%hh` 并与完整 MIME part 集合的规范化 Content-ID 匹配，不再只相信解析器的附件分类。
- 只有正文真正引用、成功清洗并进入最终 HTML 的 PNG/JPEG/GIF/WebP CID part 才从附件列表排除；阿里云等发件方将图片错误声明为 `application/octet-stream` 时，使用解码字节文件魔数确认真实图片类型，不信任文件名或错误 MIME 声明；未引用、不受支持或文件魔数不匹配的 part 继续作为附件。
- 邮件自带 `data:image` 只保留通过 media type、编码、文件魔数、单项 25 MB 和单封累计 100 MB 校验的 PNG/JPEG/GIF/WebP；SVG、HTML、错误格式和超限内容继续移除。
- 迁移 0021 将数据格式升级到 21 并失效旧安全 HTML 缓存；迁移 0022 针对已应用 0021 的实机数据再次失效缓存并升级到 22，使 `application/octet-stream` CID 图片从账户隔离的本地原始 EML 离线重建，并在同一事务更新正文与重复附件投影。

## 分页、通知与窗口

- 阅读偏好新增默认开启的“滚动到底时自动加载更多邮件”；普通文件夹和搜索结果接近底部时复用现有 TanStack Query 游标分页，关闭后恢复手动按钮。
- 同步批次的通知候选在创建窗口前裁剪：层叠保留最后 `X` 封，覆盖只保留最后一封，再统一排布，避免窗口高速闪动。
- Composer、设置、账户管理、原始邮件和通知窗口改为隐藏创建；完成代码块加载与首批查询后才显示并按窗口类型决定是否聚焦。普通窗口 Capability 只增加自身 `show`/`setFocus`，通知只增加自身 `show`。

## 安全与架构

- React 仍不解析 MIME、不访问 SQLite、原始 EML或本地文件路径；阅读偏好、正文和附件投影通过稳定 DTO/Repository 边界处理。
- iframe CSP、sandbox、远程图片默认阻止和系统外链边界不变；没有新增脚本、同源、表单、顶层导航、任意文件或任意网络权限。
- 通知 DTO 仍不携带正文、预览、附件、路径或凭据；批次裁剪只改变窗口呈现数量。

## 验收

- 2026-07-27，用户确认本阶段功能及阿里云 `application/octet-stream` CID 图片兼容验收通过。
