# 变更 0056：富文本编辑器保真与链接能力

日期：2026-07-28

## 已完成的编辑区修复

- 第十七阶段将共用富文本编辑器的正文滚动改为覆盖式自绘滚动视口。
- Composer 位于完整 flex 工作区中，正文能够获得剩余高度；签名和模板弹窗的编辑器边框容器不是 flex 容器，绝对定位的滚动视口因此被压缩到零高度。
- 工具栏和其他字段仍正常显示，但正文没有有效的点击与输入区域。

- 将签名/模板编辑器的有界边框容器设为 flex，使共用 `RichTextEditor` 作为 flex 子项稳定占满剩余区域。
- 保留既有最小高度、弹窗内滚动条、HTML 双栏编辑、保存 DTO 与中英文文案，不改变 Composer 布局。
- 扩展设置页回归测试，断言定义字段保持内容高度，同时富文本容器具备有界 flex 视口。

## HTML 源码与 WYSIWYG 边界

- Composer、签名和模板现在都把已经持久化的 `DraftContent.html` 显式传给共用编辑器。只打开、编辑或往返 HTML 源码时，不再先用 Tiptap 序列化结果覆盖源码，因此根级裸文本不会仅因进入源码模式就被添加 `<p>`。
- 从源码返回 WYSIWYG 只建立结构化投影；只有用户随后在可视化编辑器内实际输入、粘贴、执行格式命令或替换模板/签名时，才按 ProseMirror schema 重新序列化。
- 保持 Tiptap 作为受约束结构编辑器，不引入执行任意 DOM 的编辑器，也不绕过 Rust 保存前清洗。

## 样式和图片尺寸

- 增加纯内联 `div` 节点，保留没有块级子节点的邮件容器，避免无理由插入段落包装。
- 图片节点继续保留安全 `src`/CID、替代文本和标题，并补齐 class、ID、width/height、align、border、hspace、vspace 与行内 style 的解析、DOM 呈现和序列化。
- 删除编辑画布对所有图片强制 `max-width: 100%`、`height: auto` 的覆盖；超宽邮件内容沿用现有横向滚动，不重写图片数据。

## 链接工具

- 共用工具栏新增链接设置/更新和移除入口；没有文本选区时，以规范化 URL 作为可见文本插入。
- 使用 NextMail 自有输入框、按钮和中英文文案，不调用浏览器原生 `prompt`。
- 前端只接受 `http`、`https`、`mailto`，并拒绝用户信息、反斜线、控制字符、双向控制符和混淆编码；保存时仍由 Rust 使用同一安全边界重新校验。
- 编辑器内链接保持不可直接打开，最终 HTML 固定使用 `_blank`、`noopener noreferrer`。

## 独立编辑窗口与插图

- 设置页不再在 780px 弹窗中承载签名/模板编辑器；新增和编辑通过 `src/app/api.ts` 打开独立窗口，窗口内容就绪后再显示，并沿用首次居中、后续大小/位置记忆和 Windows/macOS 标题栏规则。
- 为动态 `definition-*` 窗口补充独立的最小 Tauri capability，使事件监听、就绪后显示、聚焦和标题栏控制不会被运行时权限系统拒绝；不向该窗口开放文件系统、网络或对话框权限。
- 独立窗口按公开范围和定义 ID 自行加载、保存；Rust 保存成功后发布不含正文的最小变更事件，设置窗口据此失效对应模板、签名和默认签名 Query。
- 共用编辑器的图片回调支持两种明确来源：Composer 继续插入草稿附件缓存的 CID；签名/模板插图使用经过 Rust 预处理的受限 data URL。
- 定义插图仅接受 PNG/JPEG/GIF/WebP，前端在读取前限制 3 MiB，Rust 再验证 MIME、Base64、文件魔数和大小；不接受 SVG、HTML、未知格式或伪装扩展名，不下载远程图片。
- 图片 data URL 同定义 HTML/JSON 持久化并继续经过保存前清洗，不新增迁移、定义附件表或临时 CID。
