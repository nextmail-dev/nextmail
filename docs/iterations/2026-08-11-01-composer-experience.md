# Composer 交互体验优化

日期：2026-08-11

## 状态

已验收。

## 范围

- 将邮件详情标题字号调整为与邮件列表中的文件夹标题一致。
- 统一 Composer 发件人、收件人、抄送、密送和主题栏之间的细分隔线。
- Composer 默认显示抄送栏；将原“抄送/密送”按钮替换为单独的非 ghost 密送按钮，只控制密送栏显隐。
- 联系人候选列表支持方向键上下选择和 Enter 确认。
- 富文本编辑器接管 Tab，插入可随 HTML 邮件保留的制表空格，不把焦点移出编辑器。
- 移除 primary 按钮悬停时的上移动画。
- 让回复与转发使用各自明确、与横线同一行的原始邮件标题。

## 非目标

- 不改变收件人解析、草稿保存、模板覆盖或发件语义。
- 不改变联系人候选排序、数量或账户隔离规则。
- 不新增依赖，不调整全局分隔线或字体规范。

## 验证门禁

- 邮件详情标题与文件夹标题均使用 `text-xl`。
- 新建及既有草稿始终显示抄送栏；密送按钮可反复显示和隐藏密送栏，已有密送地址不丢失。
- 候选列表可用 ArrowUp/ArrowDown 移动选中项，Enter 选择当前项；未选中候选时保留原有 Enter 提交自由输入行为。
- 富文本编辑器按 Tab 后焦点不离开编辑器，并插入四个可序列化的不换行空格。
- 相关 Vitest、`pnpm build` 和 `git diff --check` 通过。

## 实施结果

- 邮件详情标题在普通与大屏断点均改为 `text-xl`，与邮件列表的文件夹标题字号一致。
- Composer 的发件人、收件人、抄送、密送和主题栏统一使用 1px、`border/70` 颜色的细分隔线。
- 抄送栏改为始终显示；原“抄送/密送” ghost 按钮和对应中英文文案已移除，替换为只控制密送栏的 secondary 按钮。草稿或模板已有密送人时仍会自动展开密送栏。
- 收件人输入改为可访问的 combobox；候选数据继续使用原账户范围 Query，ArrowUp/ArrowDown 循环选择，Enter 选择当前候选，鼠标悬停与键盘选中共享高亮状态。
- 富文本编辑器接管 Tab 并插入四个不换行空格；默认焦点切换被阻止，序列化 HTML 保留为四个 `&nbsp;`。

## 手动验收

- 在主窗口分别以窄屏和宽屏打开邮件，确认邮件标题与“收件箱”标题字号一致。
- 新建邮件，确认抄送栏默认可见、密送按钮有实体背景且只切换密送栏，所有地址与主题栏分隔线视觉一致。
- 在收件人、抄送和密送栏输入联系人关键字，用上下方向键移动高亮并按 Enter 选择。
- 在富文本正文中按 Tab，确认插入约四个空格且焦点不跳到工具栏或下一控件；保存并重新打开草稿后空格仍存在。

## 手动验收反馈与修正

- 用户实机截图确认 Composer 地址区的分隔线仍在 Windows 缩放下呈现粗细交替。根因是独立 `h-px` 分隔元素会占用 1 CSS px 高度，在 150% 等非整数缩放下逐行累计半个物理像素偏移，导致相邻线条交替栅格化为不同粗细。
- 发件人、收件人、抄送、密送和主题行改为在自身 `border-box` 内绘制统一的 `border-bottom`，删除这些行之间额外占高的 Separator；模板栏与编辑器工具栏之间原有的独立区域分隔保持不变。
- Composer 左侧标签从 `text-xs` 增大为 `text-sm`，并在固定宽度内使用末行两端对齐，使中文两字与三字标签占据一致视觉宽度；复用同一组件的结构化模板编辑表单继续保留原字号和布局。
- 从共享 Button primary variant 移除 `hover:-translate-y-px`，所有 primary 按钮悬停时只改变颜色，不再上移。
- 修正后相关测试 3 个文件、13 项通过；`pnpm test src` 39 个文件、134 项全部通过；`pnpm build` 通过，仅保留既有大 chunk 警告。

## 回复与转发原文标题

- 回复和回复全部的原文标题改为“回复的原始邮件”，转发改为“转发的原始邮件”；英文分别为“Original message — Reply”和“Original message — Forward”。
- HTML 标题由上方横线改为单一 flex 容器：标题位于左侧，`hr` 在右侧占满剩余宽度；纯文本同步改为“标题 ----------”。用户明确接受旧版 Outlook 可能不支持 flex、将横线退化到下一行的兼容性取舍。
- 标题继续位于 `nextmailOriginalMessage` 原子节点的 `sourceHtml` / `sourcePlainText` 内，没有改变原文隔离、清洗、模板插入或发件边界。
- `cargo fmt --all -- --check`：通过。
- `cargo test --offline --locked`：168 项全部通过。
- `cargo clippy --offline --locked --all-targets -- -D warnings`：通过。
