# 阅读体验与批量操作修正

日期：2026-08-09

## 状态

已验收（2026-08-09）。

## 范围

- 邮件详情中的收件人、抄送和密送默认限制为一行；确有溢出时提供 ghost 样式的展开/收起按钮，展开前不继续挤压正文。
- 正文按需加载期间只显示 spinner，不显示空状态、阶段文案或进度条。
- 每个邮件附件增加“打开所在文件夹”动作，继续由 Rust 在账户归属校验后准备安全缓存副本并调用系统文件管理器，不向 React 暴露路径或新增 Shell 权限。
- 移除所有业务窗口左上角仅重复当前页面身份的标题文案；保留拖动区域、Windows 窗口控制和 macOS 原生交通灯。
- 邮件列表支持常见桌面多选语义，并让右键菜单对当前选择执行已有的已读、星标、移动、复制、归档和删除操作。
- 联系人列表支持相同的多选语义和批量删除；删除只影响当前账户的本地联系人并直接移除记录，后续收信再次发现同邮箱时允许自动重建。

## 非目标

- 不增加跨文件夹或跨账户的混合选择，不增加批量导出、联系人分组、撤销中心或通用文件管理器权限。
- 不改变 IMAP 操作队列、安全 EXPUNGE 降级、邮件 sandbox、账户隔离或附件内容存储边界。
- 不提交、推送、打 tag、发布或运行 Tauri bundle，除非用户另行明确要求。

## 验证门禁

- 收件人单行折叠只在真实溢出时出现按钮，展开/收起可由键盘操作，窗口宽度变化后状态正确。
- 附件文件夹动作复用账户校验、安全文件名和缓存路径，普通与高风险附件均只定位而不执行。
- 多选覆盖单击、Ctrl/Cmd、Shift 范围选择、右键未选中项切换选择，以及选择在账户、文件夹、搜索与分页变化后的收敛。
- 批量邮件操作仍通过持久化待办保证离线与重启恢复；批量联系人删除严格限制当前账户，删除后自动发现可重新创建联系人。
- 执行前端测试与构建、Rust fmt/test/clippy、迁移验证及 `git diff --check`；不运行 Tauri bundle。

## 实施结果

- 邮件详情的 To/Cc 地址行使用实际内容高度检测；默认裁切为一行，只在发生换行时显示可键盘操作的 ghost 展开/收起按钮，折叠时不会把隐藏地址留在 Tab 顺序中。
- 正文按需加载态收敛为单一 spinner，并移除前端不再消费的正文进度订阅与进度 UI；正文失败后的错误提示和重试入口保留。
- 附件卡片增加“在文件夹中显示”；Rust 复用账户校验、安全缓存副本和既有系统文件管理器 Adapter，普通及高风险附件均只定位目标文件，React 不接收内部路径。
- 所有业务窗口的 React 标题栏移除左上角重复名称，保留分平台背景、拖动区域、Windows 控件与 macOS 原生交通灯。
- 邮件和联系人列表复用同一桌面多选状态，支持单击、Ctrl/Cmd、Shift 范围与右键选择保持；列表标题在多选时显示数量。
- 邮件右键菜单对当前选择批量执行已读、星标、移动、复制、归档和删除，继续复用既有持久化 IMAP 待办；回复、转发、编辑草稿和独立窗口等单封动作只在单选时出现。
- 联系人右键菜单保留复制、写信和编辑，并支持当前选择批量直接删除；Rust 在事务中复验全部联系人属于当前账户后物理删除，邮件关联通过外键级联清理，后续同步可重新创建同邮箱联系人。
- 开发流程改为按日期与计划主题记录 iteration，不再新增阶段编号；无指定版本的“发布”请求固定从最新有效 SemVer tag 自动递增 patch 后提交、推送并推送 tag。
- GitHub Release 工作流按当前 tag 从根目录 `CHANGELOG.md` 提取对应版本段落，不再使用固定发布正文或 GitHub 自动生成日志。

## 手动验收建议

1. 打开 To/Cc 很多的真实邮件，调整窗口宽度，确认默认各占一行、仅溢出时出现展开按钮，展开后所有地址仍可显示名片和右键菜单。
2. 对未下载、已下载和高风险扩展名附件分别点击“在文件夹中显示”，确认只打开系统文件管理器并选中安全缓存副本。
3. 在 Windows 与 macOS 检查主窗口及所有独立窗口左上角不再出现标题文案，拖动、交通灯和 Windows 控件保持正常。
4. 在邮件及联系人列表分别验证单击、Ctrl/Cmd、Shift 和右键未选中项；对多封邮件执行移动/删除，对多个联系人执行删除并确认账户隔离。
