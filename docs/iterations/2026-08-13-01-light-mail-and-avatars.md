# 浅色邮件表面与身份头像优化

状态：已验收

## 目标

- 浅色模式下将邮件中的纯白背景映射为与 App 阅读面板一致的表面色，避免外围留白与正文形成异色框。
- 联系人、邮件发件人与账户头像统一使用主题渐变；修复左上角账户头像阴影被父容器裁切。

## 范围

- 仅转换清洗后邮件中解析为不透明纯白的背景，其他浅色、品牌色、图片和视频保持原样。
- 复用现有安全静态 cascade，不放宽 iframe sandbox，不把邮件节点挂入主 React DOM。
- 增加共享 `IdentityAvatar` 视觉原语，并替换联系人、发件人和账户入口的重复头像样式。
- 账户文本继续自行处理宽度和换行，只移除头像祖先上的阴影裁切。

## 实施结果

- 浅色邮件复用现有安全 cascade，将不透明纯白背景写回为阅读面板 `#fbfcfe`；`#fefefe` 等近白色及媒体元素不变。
- 新增共享 `IdentityAvatar`，联系人、邮件发件人与账户入口统一使用已有主题主色渐变。
- 账户头像保留现有阴影，移除按钮和身份行的 `overflow-hidden`，仅由文本栈负责内容约束。

## 非目标

- 不按联系人生成随机颜色或持久化头像配色。
- 不修改联系人数据模型、账户 DTO 或头像图片能力。
- 不处理 2026-08-12 两轮已验收同步改动。

## 验证门禁

## 手动验收

- 2026-08-13：用户实机验收通过。
- 在浅色模式下打开纯白底邮件，确认正文背景与阅读面板融为一体；打开带近白或品牌底色的邮件，确认作者底色未被替换。
