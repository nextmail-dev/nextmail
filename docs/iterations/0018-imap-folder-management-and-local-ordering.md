# 第十八阶段：IMAP 文件夹管理与本地排序

## 状态

已验收。

验收日期：2026-07-27。

## 目标

在不改变现有账户同步调度、消息待办队列和每账户有界 IMAP 会话模型的前提下，补齐 IMAP 文件夹的基础管理能力，并允许用户按本机偏好调整文件夹展示顺序。

## 范围

### IMAP 文件夹管理

- 文件夹右键菜单提供：
  - 创建子文件夹；
  - 重命名；
  - 移动到根级或另一个文件夹下；
  - 删除；
  - 标记全部已读。
- 创建、重命名、层级移动和删除属于需要在线完成的服务器操作：
  - Rust 根据 `account_slot_id` 和本地 mailbox ID 解析服务器路径；
  - Adapter 复用账户级有界交互会话执行 IMAP `CREATE`、`RENAME`、`DELETE`；
  - 账户级 mailbox 路径读写锁让结构操作等待正在使用旧路径的同步、正文或待办完成，不取消既有操作；
  - 只有服务器确认成功后，Repository 才以事务更新本地投影；
  - 不把协议库类型或服务器路径暴露给 React。
- 标记全部已读通过一次文件夹级 IMAP `UID STORE 1:* +FLAGS.SILENT (\Seen)` 完成，成功后事务更新本地 Flags 与未读计数。
- `INBOX` 不允许重命名、移动或删除；不可选择文件夹不提供标记全部已读。
- 文件夹叶名称必须非空，不得包含控制字符或服务器层级分隔符；移动不能以自身或自身下级为目标。
- IMAP 修改后的错误继续统一映射为稳定 `CommandError { code, params, retryable }`，具体服务器错误只进入日志。

### 本地文件夹排序

- 排序偏好存储在可迁移数据目录的 SQLite 中，并按匿名 `account_slot_id` 隔离。
- 初次使用仍保留当前系统文件夹优先和名称排序；用户完成一次拖拽后，显式顺序成为该账户的本地展示顺序，新发现文件夹追加在显式顺序之后。
- 展开文件夹栏中，长按文件夹后进入拖拽状态，拖到同层目标的上半区或下半区并松开即可排序。
- 拖拽只调整同一父级下的本地展示顺序；改变服务器层级必须使用“移动”菜单，避免一个手势同时表达本地排序和远端重命名。
- 父文件夹移动排序时，其下级作为一个连续子树随父级移动。
- 折叠文件夹栏不提供拖拽排序，但保留可用的右键菜单。

## 架构落点

- `core`：新增稳定的文件夹远端操作 DTO/port，不依赖 async-imap、SQLx 或 Tauri。
- `protocols/imap`：在操作级会话中实现 `CREATE`、`RENAME`、`DELETE` 和批量 `\Seen`；Unicode 叶名称编码为 IMAP modified UTF-7；账户级路径读写锁只串行结构变更，不破坏普通操作共享并发。
- `storage`：新增文件夹专用 Repository，负责上下文解析、重命名树事务、本地删除/已读投影和顺序持久化。
- `mail_runtime`：校验账户可写状态，先读取短生命周期上下文，再执行网络操作，最后落本地事务并发出失效事件；不持有 SQLite 事务等待网络。
- `commands` / `src/app/api.ts`：只暴露账户 ID、mailbox ID、叶名称、目标父 mailbox ID 和有序 mailbox ID 列表。
- `features/mail`：右键菜单、确认/输入弹层与长按拖拽交互；TanStack Query 仍是文件夹视图唯一数据源。

## 非目标

- 不增加 POP3、OAuth、IMAP IDLE、订阅管理、服务器 ACL/共享邮箱管理。
- 不改变启动、账户间隔和手动完整同步的三类触发规则。
- 不把文件夹管理加入离线待办队列；本阶段的服务器文件夹结构变更需要在线成功。
- 不通过拖拽改变服务器层级。
- 不运行 Tauri bundle，不新增 Node 或 Rust 依赖。

## 手动验收

1. 在支持 IMAP 文件夹管理的真实账户上，分别创建根级文件夹和子文件夹，确认 Web 端与 NextMail 均可见且层级一致。
2. 重命名带下级的文件夹，确认父级与下级只保留新路径，邮件内容和未读计数不丢失。
3. 将普通文件夹移动到根级和另一个文件夹下，确认服务器 Web 端层级一致；尝试移动到自身/下级时应被明确阻止。
4. 删除测试文件夹，确认服务器和本地列表均移除；服务商拒绝删除非空文件夹时应显示稳定错误且本地不提前消失。
5. 对有未读邮件的文件夹执行“全部标为已读”，确认列表、计数和服务器 Web 端一致。
6. 长按同层文件夹并拖到目标上方/下方，松开后确认顺序即时刷新；重启应用、手动同步后顺序仍保持。
7. 确认拖拽父文件夹时下级整体随动，跨层拖拽不会改变顺序或服务器路径。
8. Windows 10 22H2+ 检查右键菜单、弹层、主题色、浅色/深色与键盘关闭行为；macOS 行为只在实机执行后记录结果。
