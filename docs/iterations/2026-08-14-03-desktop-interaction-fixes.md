# 桌面交互与实机问题修正

状态：已验收

## 目标

修复实机测试发现的下拉列表、macOS 主窗口恢复、列表选择和文件夹拖动反馈问题，并补齐 Composer 文件拖入附件、签名分界及通知设置禁用态。

## 范围

- 约束共享下拉列表不超出视界，项目过多时使用覆盖式纵向滚动条。
- macOS 关闭主窗口后，点击 Dock 图标可重新显示并聚焦主窗口。
- Composer 接收系统文件拖入并复用现有附件导入链路。
- 邮件与联系人列表的单击选中项再次单击取消选择。
- 联系人当前项左侧标识条与邮件列表对齐。
- 通知总开关关闭时禁用全部从属设置。
- Composer 签名上方显示细分隔线。
- 文件夹拖动落点统一为圆点加横线，不再区分上下边框样式。
- 禁用未接入应用交互区域的 WebView 原生右键菜单。
- 修复 Composer 合法附件因仓储账户条件绑定错位而无法删除的问题。

## 非目标

- 不改变附件安全校验、账户隔离或发送 MIME 语义。
- 不重构列表多选规则、文件夹排序模型或通知后端。
- 不引入新的 UI、拖放或滚动依赖。

## 验证门禁

- 前端测试覆盖下拉视界约束、单击取消选择、通知从属禁用、签名分隔线和文件夹拖动落点。
- Rust 格式、测试与 Clippy 门禁覆盖 Dock reopen 事件入口；macOS 行为由实机验收确认。
- `cargo fmt --all -- --check`。
- `cargo test --offline --locked`。
- `cargo clippy --offline --locked --all-targets -- -D warnings`。
- `pnpm test`。
- `pnpm build`。
- `git diff --check`。
- 手动验收 macOS Dock 恢复、系统文件拖入和不同窗口高度下的长下拉列表。

## 实施结果

- 共享 Select、DropdownMenu 与 ContextMenu 使用 Radix 可用高度限制在视界内，长列表显示可滚动的细滑块。
- macOS 在无可见窗口的 Dock reopen 事件中复用既有主窗口显示、还原和聚焦入口。
- Composer 通过 Tauri 原生文件拖放事件复用现有附件导入链路；新邮件和回复/转发的签名上方统一保留细分隔线。
- 邮件与联系人列表支持再次单击单选项取消选择，联系人左侧标识条与邮件列表对齐。
- 通知总开关关闭时禁用全部从属设置；文件夹排序落点统一为圆点加横线。
- Tauri 为每个 WebView 的主文档与 sandbox iframe 注入固定的默认行为拦截器，全局阻止原生右键菜单，同时保留现有应用 ContextMenu 的事件传播且不放宽邮件脚本权限。
- 修正草稿附件删除 SQL 的 `draft_id` / `account_slot_id` 绑定顺序，并由同一仓储测试同时覆盖错误账户拒绝和正确账户删除。

- macOS 关闭最后一个可见窗口后，从 Dock 图标重新打开主窗口。

- 在窗口上下边缘打开长 Select、菜单和子菜单，确认浮层不越界、滚动与键盘选择正常。

- 在空白区右键不出现 WebView 菜单，并确认邮件、联系人、文件夹和附件的应用右键菜单仍可打开。
