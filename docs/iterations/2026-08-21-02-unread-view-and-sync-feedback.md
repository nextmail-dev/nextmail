# 未读视图与同步反馈收敛

状态：等待手动验收

## 范围

- 阅读区标题下不再显示持久化操作的“等待同步”提示；邮件列表既有云端待办图标保留。
- 文件夹侧栏同步进度只在用户点击“收取”发起的手动同步期间显示；启动同步和定时同步仍在后台运行，收取按钮仍按真实同步状态禁用。
- 文件夹列表把账号级“未读邮件”视图作为首个普通滚动项并默认选中，按时间倒序展示当前账号所有本地未读邮件；其右键菜单只提供“全部标为已读”。通知等明确导航仍进入邮件所在真实文件夹。
- 展开侧栏中的文件夹整行均可点击选择；没有子文件夹的项目，其为展开控件保留的左侧空白同样属于点击区域。
- 文件夹展开槽由 24px 缩至 16px，标题改为“邮箱文件夹”，并与未读视图和根级文件夹图标保持相同左侧起点。
- 邮件列表的未读实心点改为独立可交互状态按钮；已读邮件显示低强调度空心圆环，点击可在已读/未读之间切换，同时保留打开未读邮件即标为已读的既有行为。
- 新增生产文案同时提供 `zh-CN` 与 `en-US`。

## 非目标

- 不创建服务器端“未读邮件”文件夹，不改变 IMAP 同步范围或邮件文件夹结构。
- 不改变星标、移动、复制、归档、删除及多选菜单能力。
- 不改变后台启动同步、定时同步、同步事件或收取按钮禁用语义。
- 不为账号级未读视图新增跨文件夹全文搜索。

## 实施与验收记录

- `MessageViewer.tsx` 移除标题下的“等待同步”文案与图标；邮件列表行尾既有待办云端图标保持不变。
- `MainShell.tsx`、`MailboxPane.tsx` 只在手动“收取”已返回活动进度后显示侧栏进度，并在该轮进入终态后关闭；后台启动/定时同步仍会禁用并旋转收取按钮，但不展示进度卡片。
- 新增 `list_unread_messages` 窄 Command 与账号隔离的 SQLite 分页查询，复用既有 `MessageListPage`、联系人展示解析和 Query 失效前缀；未新增迁移或持久化虚拟文件夹。
- 侧栏将“未读邮件 / Unread”本地视图作为首个普通滚动项并默认选中，汇总当前账号所有文件夹未读数；右键菜单只有“全部标为已读”，内部依次复用既有真实文件夹操作。通知导航仍进入真实文件夹。
- 文件夹选择事件绑定到整行容器，展开按钮单独阻止冒泡，因此叶子文件夹的展开占位空白可点击，父文件夹的展开/折叠仍不会误触选择。
- 文件夹标题与列表根级图标统一从 26px 起点对齐，未新增额外布局层。
- 未读视图中的邮件操作按每封邮件真实 `mailboxId` 分组，详情和独立预览也使用真实位置，避免跨文件夹误操作；该视图不显示仅适用于单文件夹的搜索框。
- 邮件行左侧新增独立已读状态按钮：未读显示实心主题色圆点，已读显示淡空心圆环；点击只切换状态、不触发行选择，打开未读邮件自动标记已读的既有行为保留。移除不再使用的 `UnreadDot` 展示组件。
- 回归覆盖后台进度隐藏、手动进度展示、滚动列表内的未读视图及其单一菜单、文件夹整行点击、默认选择、账号级未读分页、真实文件夹定位、已读状态按钮和标题下提示移除。
- 自动验证：`MailboxPane` 定向测试（15 passed）、`pnpm test`（172 passed）、`pnpm build` 通过；Rust 定向测试、`cargo test --offline --locked`（190 passed）、`cargo clippy --offline --locked --all-targets -- -D warnings`、`cargo fmt --all -- --check`、`git diff --check` 全部通过。构建仅保留既有大 chunk 警告。
