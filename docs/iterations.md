# NextMail 开发记录

## 2026-08-21

- [x] 修正 HTML-only 邮件的文本提取逻辑，只从 `<body>` 生成纯文本与列表预览，不再混入 `<head>` 中的标题。
- [x] 移除阅读区标题下的“等待同步”；文件夹同步进度只在手动收取时显示，启动与定时同步继续静默运行。
- [x] 新增账号级“未读邮件”滚动列表入口并作为默认视图，支持跨文件夹查看及一键全部标为已读；邮件行使用可交互的实心/空心圆点切换未读状态。
- [x] 扩大文件夹行的点击区域，将叶子文件夹左侧展开占位也纳入选择；缩窄展开槽，并让“邮箱文件夹”标题、未读入口与根级文件夹图标左侧对齐。
- [x] 新收取的 BASE64 附件按 MIME 编码大小乘 `0.730769` 估算展示大小，附件实际下载后继续以真实字节数覆盖；不迁移历史附件。
- [x] 滚动条改为仅在指针移入滚动区时显示，不再因列表内部保有键盘焦点而持续可见。
- [x] 文件夹与邮件列表的上下方向键改为选择并聚焦相邻项目，不再触发列表默认滚动。
- [x] 收紧邮件已读/未读按钮的 hover 反馈，只在状态圆点周围显示小范围淡色环，同时保留原点击区域。
- [x] 修复重复点击当前文件夹会清空邮件选中态和阅读区的问题；只有切换到不同文件夹时才重置文件夹内状态。
- [x] 在“邮箱文件夹”上方新增“收藏夹”：真实收藏文件夹优先排列，默认包含收件箱，其后显示不可移除的账号级“星标邮件”和“未读邮件”；真实文件夹可通过右键菜单添加或移除收藏，收藏状态按账户持久化，同一文件夹只高亮实际点击的收藏入口或文件夹树入口。
- [x] 修复“未读邮件”视图中打开邮件后立即消失的问题：当前视图保留并更新已读状态，离开后再次进入才按本地数据库刷新移除。
- [x] 按账户保存最后选中的真实或虚拟文件夹，下次启动及切回账户时恢复；目标不存在时优先回退到真实收件箱。
