# 第三方资源说明

NextMail 当前不再随安装包分发 Roboto、Droid Sans Fallback 或其他第三方字体。界面使用 Windows/macOS 自带的系统 UI 字体与中文回退字体，不复制或再分发这些系统字体文件。

若未来重新引入随包字体或其他独立资源，必须在本文件记录来源、版本和许可证，并把对应许可证文本加入发布资源。
